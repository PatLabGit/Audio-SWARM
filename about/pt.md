## 📝 Sobre o Audio-SWARM

O Audio-SWARM é uma aplicação para computador que permite gerar imagens de formas de onda sonoras e visualizações circulares, bem como associar capas existentes a ficheiros de áudio. Foi concebido para ajudar os criadores a preparar elementos visuais para os seus projetos de áudio.

O Audio-SWARM cria imagens; não cria nem modifica o próprio som.

## ⚗️ História do desenvolvimento

O Audio-SWARM não começou por ser a aplicação que é hoje.

As suas origens remontam a um simples script Python, inicialmente desenvolvido e executado através do terminal. Começou como um script básico para as minhas necessidades pessoais e evoluiu depois para uma interface gráfica simples, antes de se tornar um projeto chamado **WaveStudio**: uma aplicação Tkinter de ficheiro único que reunia a interface gráfica, a geração de formas de onda, o processamento de áudio e a gestão de capas num único script de grandes dimensões.

À medida que as funcionalidades aumentaram, essa estrutura original tornou-se cada vez mais difícil de manter e desenvolver. Seguiu-se uma refatorização profunda, que dividiu a aplicação em módulos separados e estabeleceu uma arquitetura mais organizada.

Posteriormente, o projeto evoluiu para **Audio-SWARM (Audio-Sound Waveform & bulk Album/Artwork-cover batch Remix Motif)**, com uma interface redesenhada, um conjunto de funcionalidades alargado e melhorias contínuas no motor de processamento.

**Alpha 6 representa a sexta grande iteração interna de desenvolvimento** deste projeto em curso. É a primeira versão pública e o desenvolvimento continua ativo.
